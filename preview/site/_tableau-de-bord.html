Piloter la construction sans tout refaire à la main

La chaîne est entièrement rejouable : changer un texte, c’est éditer un deck et relancer.

cd "~/Desktop/EMAsphere/Rebranding EMAsphere 2026"
npm run pages      # 19 aperçus + 19 templates HubSpot, depuis content/<slug>/*.md
npm run verify     # tokens · HubL · champs · templates · contenu — doivent être verts
python3 -m http.server 8765 && open http://localhost:8765/preview/site/index.html
hs cms upload hubspot-theme "EMAsphere-Rebrand-TEST"   # avec GO explicite

Pour un équipier

  • docs/27-ONBOARDING-EQUIPE.md — première heure.
  • Skill nouvelle-page — le cadre qui pose les questions et refuse sans deck.
  • content/README.md — écrire un copy deck.

Pour choisir un module depuis le deck

  • 3-5 items en gras → grille de cartes · 6+ → carrousel · 4+ longs → accordéon
  • **01. Titre** → parcours numéroté · tableau Markdown → comparatif
  • [ Logos : A · B ] → mur de logos · [catalogue-connecteurs] → catalogue

Ce que le système garantit

  • Aucun contenu inventé : pas de deck → pas de page.
  • Une famille de forme par bande, ton selon l’archétype, composition qui varie.
  • Rien en production sans GO : thème de test séparé, live vérifié identique après chaque envoi.
